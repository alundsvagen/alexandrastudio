About BudgetBakers s.r.o.

BudgetBakers offers Wallet, a personal and family finance manager with budgeting, expense tracking and bank synchronization. It also offers Board for small-business and freelancer cash flow, ShareCost for splitting group expenses, and an AISP banking API for developers and businesses. The site reports 14M+ downloads, 50 languages, 15K+ bank connections and ISO 27001 certification, and it provides a REST API and an MCP server that connects Wallet to AI assistants such as Claude and ChatGPT.
